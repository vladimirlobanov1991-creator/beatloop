BeatLoop 0.1 — экспериментальный прототип.
Распакуйте архив. Для iPhone разместите все файлы на HTTPS статическом хостинге (например GitHub Pages, или Netlify Drop, если доступен). Откройте URL в Safari, Поделиться > На экран «Домой». Для локальной проверки Windows: python -m http.server 8000 из папки проекта; откройте http://localhost:8000.
Движок и звуки загружаются с CDN; первое открытие требует интернета. Офлайн и Safari не проверены. Библиотека хранится в IndexedDB браузера, резервные копии исходных файлов держите отдельно. Демо — оригинальный гитарный рифф для проверки звука. Импортируйте GP с ударными для проверки нот. Циклы по номерам тактов, особенности повторов и автоматическое ускорение требуют проверки на реальных файлах. Нет встроенного каталога песен. JavaScript проверен на синтаксис, не на воспроизведение.
